# Security policy

## Reporting a problem

Please don't report security problems in a public issue, because that exposes them before a fix exists.

Report them privately through [GitHub's security advisories](https://github.com/dineshdcshinde/prava-ui/security/advisories/new). Include what the problem is, how to reproduce it, and the version you're using.

You can expect a first reply as soon as the maintainer can manage. Prava UI is maintained by one person, so this may take a few days. You'll hear what's planned, and you'll be credited in the fix if you'd like to be.

## Supported versions

Only the newest published version gets security fixes.
